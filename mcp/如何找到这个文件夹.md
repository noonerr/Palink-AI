## ✅ 问题已解决！

mcp 文件夹现在在正确的位置了。

## 📍 文件夹位置

### Windows 路径
```
C:\Users\Pall\OneDrive\桌面\Palink-AI\mcp\
```

### 三种打开方式

#### 方式 1: Windows 文件管理器
1. 按 `Win + E` 打开文件管理器
2. 在地址栏输入：`C:\Users\Pall\OneDrive\桌面\Palink-AI\mcp`
3. 按回车

#### 方式 2: 从项目根目录
1. 打开 `C:\Users\Pall\OneDrive\桌面\Palink-AI\`
2. 找到 `mcp` 文件夹
3. 双击打开

#### 方式 3: 命令行
```bash
# Git Bash
cd /c/Users/Pall/OneDrive/桌面/Palink-AI/mcp
ls

# Windows CMD
cd C:\Users\Pall\OneDrive\桌面\Palink-AI\mcp
dir

# 或者直接用资源管理器打开
explorer.exe mcp
```
