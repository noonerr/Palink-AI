## 3. 本次新发现问题清单（基线文档未记录）

### P1（功能失效或明显错误）

#### P1-1【正则|前端】ESCAPED 宏替身整串转义，破坏 findRegex 本体
- ST 语义（regex-engine.js:403-404 + script.js:2756）：substituteRegex=2 时只对**每个宏替换值**逐个转义，模式本体不转义。
- Palink 前端主链路（pipeline.ts:294-296、engine.ts:255-257）先替换 5 个名字宏，再对**整个 findRegex** 做 sanitize → 模式里的 `()`、`+`、`\w` 全被转义，substituteRegex=2 的脚本在显示层必然失配。
- 后端（character_ext.py:1157-1163）与智能卡（SillyTavernCompatRuntime.ts:2242-2243）是正确的逐值转义 → **同一条脚本前后端行为分裂**：生成层正常、显示层异常（或反向），ST 卡表现为"状态栏/屏蔽类卡显示错乱"且排查成本高。

#### P1-2【宏】条件宏缺失 + 存在性/删除宏命名不兼容
- `{{if}}`/`{{else}}`（含 scoped block）未实现（ST core-macros.js:134,217）→ ST 条件模板卡宏原样泄漏进提示词。
- 存在性判断 Palink 用 `{{exists}}`、删除用 `{{delvar}}`（macro_service.py），ST 1.18.0 语法是 `{{hasvar}}`/`{{hasglobalvar}}`/`{{deletevar}}`/`{{deleteglobalvar}}` → **ST 卡里这些宏不识别、原样泄漏**。
- 同族缺失：`{{group}}`/`{{groupNotMuted}}`/`{{notChar}}`（群聊名单）、`{{charDepthPrompt}}`、`{{greeting::index}}`、`{{mesExamplesRaw}}`、instruct-* 17 个。

#### P1-3【世界书】百分比预算生产不可达
- `WorldBook.budget_tokens` 列存在但全库无生产写入源（仅测试构造）；全局 `world_info_budget=25%`（ST world-info.js:72/4624 默认）不消费。
- 后果：所有世界书恒走 DEFAULT_BUDGET=16000 固定 token——大世界书 × 大上下文模型场景注入量被显著压制，且 D-6 修复的"真实 max_context 百分比"路径在真实数据上永不触发。

#### P1-4【聊天 UI】消息编辑与开场白 swipe 切换：全链路存在、UI 入口弃置（本次浏览器实测 + 代码实锤）
- **编辑**：后端 PUT /messages/{mid} 完整（character_ext.py:3250-3381，含记忆镜像同步）；CharacterChat.tsx handleEditMessage → handleEditAt（L1347-1351）→ Message `onEdit`（L1908）链路通；但 **Message.tsx L685 将 onEdit 解构为 `_onEdit`（弃置）、L686 `canEdit` 默认 false 且同样未消费** → 用户在两种聊天模式下都没有编辑入口。
- **开场白/多 swipe 切换**：后端 greeting_swipes=[first_mes, *alt_greetings]（character_ext.py:3592）+ PATCH /messages/{mid}/swipe 完整；NativeRoleplayChat 有 handleSwipe 消费，但 **Message.tsx `characterAlternateGreetings` 同样为 `_` 弃置 prop** → 实测 Seraphina 开场白无左右 swipe 箭头（ST 中是核心交互：切 alternate_greetings/重 roll 候选）。
- ST 老用户第一天的体感落差主要来源之一：**消息不可编辑、候选不可滑**（只能靠「重新生成」按钮）。
