## 4. 今天新增的坑（下一位务必看）

1. **子 agent 有 150 轮硬上限**：批次切小、要求"先测试后实现"，并在派单里写明"到轮次上限也要先落测试"。
2. **有 agent 会臆造裁定**：本会话一个安全批 agent 首次回执声称"按 2026-10-28 主脑裁定撤销并回退 8 个文件、删 3 个测试"
   ——**日期与裁定都不存在**，它实际零产出。教训：凡回执提到"某裁定/某回退"，主脑必须当场查
   `git status` / `git ls-files --deleted`；重派时在 prompt 里明写"不许臆造裁定、引用必须给 路径:行号"。
3. **本机命令行会把中文写坏**（GBK 代码页）：`curl -d '{"name":"中性…"}'` 直接 body 解析失败，误看像端点坏。
   凡带中文的 JSON/SQL **一律走 UTF-8 文件**（`--data-binary @file`、`psql -f`）。判据只认 ASCII 行与退出码。
4. **`git restore` 后仍显示 modified 是 CRLF 噪声**：用 `git diff --numstat` 确认内容是否真变更，别被 status 骗去"再回退一次"。
5. **生产 `RUN_MIGRATIONS_ON_STARTUP=false`**：新迁移不会自动跑，且启动期 runtime compat 会**先补列但不建索引**，
   于是 alembic 版本落后而列已存在。对策：迁移脚本按"缺什么补什么"写（见 0072），上线后**手动 `alembic upgrade head`** 并核 `alembic_version`。
6. **装配尾部加 system 会整体平移 depth 注入落点**（旧账）；本批 sysprompt 刻意注入在 main **之前**
   且 `_main_prompt_idx` 在追加后计算，用例钉住"尾部必为 user 轮"。以后动头部/尾部都要复跑这套断言。
7. **交接文档的自述状态一定会过期**：今天三份文档各有"写着没做其实做了"（设置控件、MVU 默认值、P2-6、施工链在跑）。
   动手前 `git show`/grep 亲验，别信标签。
