## 0. 两件事，都必须做（不是可选）

### P3-A 三个预设键必须是**同步**的
实机实测（主脑 2026-10-21，探针 `.tmp_probe/PQ_preset_shape.js`）：
`getPresetNames` / `getLoadedPresetName` / `getPreset` 三个键**全部返回 `[object Promise]`**。
权威契约一手核到：`st-plugins/third-party/JS-Slash-Runner-main/@types/function/preset.d.ts:150`
—— `declare function getPresetNames(): string[];`（同步、返数组）。

⇒ 真卡按 ST 写法拿到的永远是 `undefined`。**"接错成异步"比"没接"更难发现**：不报错、不留痕、门禁全绿。
为什么批次P2 的 24 条单测没抓到：用例 `await` 了返回值，而 `await` 对同步值和 Promise 一样成立。

- **判据（必须写进守卫，不许只断值）**：对每个键断
  `const v = TavernHelper.getPresetNames(); expect(v && typeof v.then).not.toBe('function');`
  三条都要有，且断的是**帧内那三键**（父侧 dispatcher 内部异步是允许的，**对外必须同步**）。
- 实现路线（主脑定，不要另发明）：**宿主在 boot 上下文里带一份预设快照**（名字列表 + 当前生效份），
  帧内三键读这份快照**同步返回**；快照的刷新沿用它已有的那条通道（宿主刷新 → 帧内更新），
  ⛔ 不要在帧内做"同步等异步"的忙等或返回假值。
- ⚠️ 语义诚实：快照可能不是最新（刚改完预设立刻读）。要读最新值仍走父侧刷新后的快照；
  **拿不到就返回"空数组 / null"并 `palinkDiag` 留痕，不许返回 `undefined` 冒充"没有预设"**。
- `getPreset()` 的返回形状沿用 ST：`{ settings, prompts, prompts_unused, extensions }`
  （实机已能出这四个键）。⛔ 缺的字段仍缺，**不许补 `enabled/role/position` 之类假默认**（这是批次P2 已立的口径，保持不变）。
- 因此 `isPresetSystemPrompt` / `isPresetPlaceholderPrompt` / `isPresetNormalPrompt`
  **本批继续不做**（缺判定字段，补了只能恒 false）；`isPreset*` 留 D 的账不许动。

## 4. 提交纪律
- 开工前 `git status --porcelain` 原样贴进报告；别人的在途改动一律不碰、不一起提交。
- 临时索引提交：`GIT_INDEX_FILE=<仓内临时文件> git read-tree HEAD` → 逐项 `git add <自己的 path>` →
  `git write-tree` → `git commit-tree -p <旧 HEAD>` → **`unset GIT_INDEX_FILE`** →
  `git update-ref <ref> <新> <旧>` → 最后 `git reset -q HEAD -- <自己的 path>`（**顺序不能反**，
  带着 `GIT_INDEX_FILE` 跑 reset 会打到临时索引，留下幽灵 `MM`/`D`）。
- ⛔ 禁止 `git add -A` / `git add .` / `--no-verify` / amend 别人的提交。
