# 批次 G — 模板串字面量守卫（把"注释里不许反引号"从人记变成跑就红）

## 为什么需要
今天两次踩同一颗雷：往 `runtime-body/part-*.ts` 的**注释里**写反引号 ⇒ 那段注入 iframe 的大模板字符串被提前闭合，
`tsc` 只报 5 个 TS1005、不告诉你哪一行是元凶；其中一次是 agent 在被截断前没跑任何检查，工作区停在编译不过的状态。
禁令写在提示词里拦不住，只能做成守卫。

## 做什么
在 `smart-card-runtime/__tests__/` 下新增一份**纯字面量**守卫（不需要求值、不看产物）：
1. 对 `runtime-body/part-01.ts … part-08.ts` 逐文件断言：
   - 反引号（` sprintf("%c",96) ` 那类字符）**计数恒为 2**（文件首尾的模板定界符各一）；
   - `${` 计数为 0；
   - 裸反斜杠位点：允许"成对反斜杠"，出现**奇数个连续反斜杠紧跟 d/s/w/S** 之类正则字母时报错并给出行号
     （这是本仓实测过的静默降级形态）。
2. 报错信息要能直接定位：打印 `文件名:行号: 片段`，别只说"计数不对"。
3. 断言写成**先红后绿**的诚实形状：先确认它对当前 8 个文件全绿（今天已修好），
   再反证——在某个 `part-*.ts` 里临时插一行注释带反引号 ⇒ 必须红；还原 ⇒ 绿，`git status` 干净。
