Palink AI 报错提示系统 UI 设计原型2026-10-03

基于项目现有设计系统，重新设计所有错误、警告、成功、加载提示的展示形式。遵循 顶部避让、简约一致、移动优先 原则。

1. 顶部常驻错误通知D2-B方案

设计理念：错误不再挤在底部（与键盘/dock/输入框冲突），改为顶部常驻卡片，带明确的关闭和重试按钮。 避开 safe-area-inset-top，避免被灵动岛遮挡。

1.1 网络错误

角色对话
网络连接问题
无法连接到服务器，请检查您的网络连接。
尝试切换网络或稍后重试
你好！我是你的AI助手，有什么可以帮到你的吗？
帮我写一首关于春天的诗

1.2 服务器错误

服务器错误
服务器暂时无法处理请求（500），我们正在修复。
请稍后重试或联系客服

1.3 超时警告

请求时间较长
AI模型正在处理您的请求，这可能需要一些时间。
请耐心等待，或切换其他模型

2. 轻量气泡提示Sonner归一

瞬时提示（成功、警告、加载状态）使用居中气泡，3秒自动消失。对齐 sonner 组件，位置 top-center。

成功提示

消息已发送

警告提示

网络连接较慢

3. 网络状态横幅顶部避让

网络连接状态使用全宽横幅，从 safe-area-inset-top 开始，避免被灵动岛遮挡。

离线状态

网络连接已断开

已恢复

网络已恢复

4. 系统消息节点extra.ignore

失败消息不再伪装成 AI 回复，改为带 extra.ignore=true 的系统提示节点， 嵌入聊天流中，可见、可重发、但不回喂模型、不被 TTS 朗读。

角色对话
你好！我是你的AI助手。
给我讲个笑话
消息发送失败
网络连接问题，无法连接到服务器。请检查您的网络连接后重试。
（重试后）给我讲个笑话
好的！有一天...

5. 技术规格实现细节

5.1 错误类型与图标映射

5.4 对比度检查（WCAG AA）

文档已确认 text-destructive 在两个主题下都不达标（暗色 2.11:1，亮色 3.76:1）。 新设计遵循 "红色只用于底色/描边/图标，正文文字使用 foreground" 原则，确保可读性。
