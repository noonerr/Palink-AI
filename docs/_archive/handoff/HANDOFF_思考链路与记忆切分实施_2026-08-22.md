3. **PowerShell 坑**：`docker exec python -c "..."` 内嵌引号会被转义搞坏（用脚本文件 + docker cp 代替）；`::` 节点 ID 被 PS 解析坏（用 `-k` 代替）；`cmd /c` 被禁用
4. **pytest 单文件直跑某些测试会报 `'app' is not a package`**（环境抖动）：以 `pytest tests/` 全量跑为准
5. **测试基线判定法**：任何"新增失败"先用 `git stash push -- <改动文件>` 跑全量对照基线再下结论
6. **备份目录**：`_backup/20260822_semantic_chunk/`（7 文件）与 `_backup/20260822_reasoning_pipeline/`（4 文件）——回滚直接覆盖
7. **st-compat / st-native 已封存冻结**：任何改动只落 palink-native 路径（AGENTS.md 声明）
8. **【重要】聊天中输出字面尖括号标签会被吞**：对话里粘贴/输出含 think 等标签的文本时，开标签之后的内容会被渲染层当作思考块吞掉（2026-08-23 实测：交接提示词两次在标签处截断）。规避：聊天与提示词中一律用文字描述（如「think 标签」），不写裸标签；磁盘上的 Markdown 文档不受影响
