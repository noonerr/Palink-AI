## 1. 帧内 5 个读类键

- 落点：`frontend/src/components/ui/custom/smart-card-runtime/runtime-body/part-07.ts`；
  宿主快照由 `SillyTavernCompatRuntime.ts` / `CharacterCardRenderer.tsx` 组装进 boot 上下文
  （`extension-catalog.ts` 提供目录形状）。
- ST 契约一手锚点（主脑已复核）：`st-plugins/third-party/JS-Slash-Runner-main/@types/function/extension.d.ts:2/5/15/40`
  —— `isAdmin(): boolean`、`getTavernHelperExtensionId(): string`、`getExtensionType(id)`、
  `isInstalledExtension(id)` **都是同步**；因此宿主要在挂载前把快照带进 ctx，帧内同步读，
  ⛔ 不能靠异步 `requestParent`。
- **`isAdmin` 真值来源**：新增 `frontend/src/lib/current-user-role.ts`，由 `App.tsx`
  在登录态变化时写入 `user.role`（与 `App.tsx:896` 的 `user?.role === 'admin'` **同一口径**）。
  宿主未下发时按**安全默认 false** 并留痕；⛔ 不从帧内 payload 取、不恒 true/false。
  ⚠️ **它不是权限边界**：后端每个写端点仍自己鉴权，它只让卡片知道"该不该显示管理入口"。

## 2. `getExtensionStatus` 的真实契约（本批最容易被写错的一个）

- `@types/function/index.d.ts:47`：`getExtensionStatus: typeof getExtensionInstallationInfo` —— **它是别名**，
  不是"是否启用"。
- `src/function/extension.ts:23-39`：`getExtensionInstallationInfo(id): Promise<ExtensionInstallationInfo | null>`，
  内部 POST `/api/extensions/version` 取 `{current_branch_name, current_commit_hash, is_up_to_date, remote_url}`。
- 本仓实现：父侧动作 `getExtensionStatus` 按该形状返回，**另附 Palink 字段 `enabled`**（UI 需要）。
  ⚠️ **本仓没有远端版本通道**（那是 R2）⇒ `is_up_to_date` 的语义是"没有可更新到的新版本"，
  **不是**和 ST 一样的远端比对结果；R2 引入远端版本后必须重算，别把当前值当"已是最新"的证据。

## 3. 后端：`owner_scope` 与 toggle 作用域（**这是一条真实的安全收紧**）

- `GET /api/plugins/runtime/config` 每个 item 新增 `owner_scope`（`global` = `user_id IS NULL`；
  `local` = 本人私有）。作用域过滤本来就有，但**分不出"全局"与"本人私有"**，帧内无法回答 local/global。
- `PUT /api/plugins/{id}/toggle` 的口径变了（`backend/app/api/plugins.py`）：
  **改前** `Depends(get_admin)` + 只按 id 查库 ⇒ 管理员能切到**别人**的私有插件；
  **改后**：本人私有 ⇒ 允许；全局 ⇒ 仅管理员（否则 403）；**他人私有 ⇒ 404**
  （不用 403，避免"这个 id 存在但你不配"的可探测性，与 `get_plugin_asset` 等既有口径一致）。
  测试：`backend/tests/test_plugin_toggle_scope.py` 6 例（含"他人插件 toggle → 404"）。

## 4. 启停为什么是斜杠命令而不是 TavernHelper 键

ST 把这一族暴露成命令：`public/scripts/extensions-slashcommands.js:89 / 130 / 171 / 230 / 266`
（`extension-enable` / `extension-disable` / `extension-toggle` / `extension-state` / `extension-exists`），
`@types/function/` 里**没有** enable/disable 成员 ⇒ 按"没有对应函数就不要自造键名"，
本批只补命令（`frontend/src/lib/slash-engine/st-compat-commands.ts`），帧内 `triggerSlash(...)` 可达；
`extension-toggle` 支持 `state=true/false` 显式设，缺省取反。

## 6. 全量门禁抓到的"单跑绿、全量红"（主脑修）

首次全量 `gate.sh backend`：**`1 failed / 2307 passed`**（修后 **2308 passed / 0 failed**），失败是
`test_plugin_toggle_scope.py::test_runtime_config_exposes_owner_scope` 的 **KeyError**（插件不在返回列表里）。
单跑该文件 6 passed、换一个前置文件跑也 21 passed ⇒ **只在全量里出现**。
根因判定（**最可能，未能构造最小复现**；判据是修后全量复跑变绿）：`runtime/config` 有 **30 秒内存缓存**（`plugins.py` 的 `_build_sillytavern_runtime_config`，
`@cached(ttl_seconds=30, key_prefix=...)`）；本 fixture **直接写库、不经 API**，
不会触发 `_invalidate_runtime_config_cache()`，于是可能读到上一个用例缓存下的"还没有这些插件"的旧快照。
修法（**只改测试**）：fixture 建完插件后、以及 teardown 时各调一次
`_invalidate_runtime_config_cache()`（`test_plugin_toggle_scope.py`）。
⚠️ 生产路径不受影响：插件的增删改都走 API，走 API 就会失效缓存。这条写在这里是为了让后来者
**别再把它当代码回归**去改 `plugins.py`。
