# S3 合并提示词（主控委派）

> 用途：把 `s3-switch-default` 合并进主分支 `three-tracks-merge-20261012`。
> 建议模型：**Step5 或 Hy4**（机械活，但涉及主分支且要判断冲突，**不要用 DeepSeek Flash**）
> ⚠️ **必须串行**：合并期间不能有其他 agent 在跑（主分支是共享状态）

## 给这个 agent 的两条提醒

1. **遇到冲突就停**。这份活的价值在于"机械地执行 + 忠实地验证"，不在于"聪明地解决"。合并冲突尤其是 src 冲突的取舍权在主控。
2. **门禁数字必须完全对上 984 / 0 / 3**。多一个少一个都要停 —— 因为那意味着合并进来了预期外的东西。
