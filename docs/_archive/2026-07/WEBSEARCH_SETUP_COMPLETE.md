## 🔒 安全建议

### 1. 限制访问（可选）

如果担心被滥用，可以配置防火墙只允许 Palink-AI 服务器访问：

```bash
# 在香港服务器上
sudo ufw delete allow 8888/tcp
sudo ufw allow from <Palink-AI服务器IP> to any port 8888
```

### 2. 启用 HTTPS（推荐）

使用 Nginx + Let's Encrypt 配置 HTTPS：

```bash
# 安装 Nginx
sudo apt install nginx certbot python3-certbot-nginx

# 配置域名（假设你有域名 search.yourdomain.com）
sudo nano /etc/nginx/sites-available/searxng

# 添加配置
server {
    listen 80;
    server_name search.yourdomain.com;
    
    location / {
        proxy_pass http://localhost:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# 启用站点
sudo ln -s /etc/nginx/sites-available/searxng /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 获取 SSL 证书
sudo certbot --nginx -d search.yourdomain.com
```

### 3. 监控资源使用

```bash
# 查看容器资源使用
sudo docker stats searxng searxng-redis

# 查看磁盘使用
sudo du -sh /opt/searxng
```

### 问题 3: 搜索返回 500 Internal Server Error

**症状**: `500 Internal Server Error`

**解决方案**:
```bash
# 查看日志
sudo docker logs searxng --tail 50

# 通常是配置文件格式错误，使用最小化配置
sudo bash -c "cat > /opt/searxng/searxng/settings.yml << 'EOF'
use_default_settings: true
server:
  secret_key: \"$(openssl rand -hex 32)\"
  limiter: false
redis:
  url: redis://redis:6379/0
EOF
"
sudo docker restart searxng
```
