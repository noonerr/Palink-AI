- 开工前 `git status --porcelain` 原样贴进报告；工作区里别的包的在途改动**一律不碰、不一起提交**。
- 用**临时索引**提交：`GIT_INDEX_FILE=<仓内临时文件> git read-tree HEAD` → 逐项 `git add <自己的 path>` →
  `git write-tree` → `git commit-tree -p <旧 HEAD>` → `unset GIT_INDEX_FILE` →
  `git update-ref refs/heads/<分支> <新> <旧>` → 最后 `git reset -q HEAD -- <自己的 path>` 清幽灵条目
  （⚠️ **顺序不能反**：带着 `GIT_INDEX_FILE` 跑 reset 会打到临时索引，留下 `MM`/`D` 幻象）。
