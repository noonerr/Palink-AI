## 6. 结论

1. **两卡口径闭合状态**：首版 12 条编号在本卡全部得到交代（10 复现 + D-2 条件性 + D-4 未复现），无一条被本卡推翻；主脑 §7.2 裁定表（D-3/D-4/D-5/D-6/D-7/D-9/D-12 的归宿）**不受本卡影响，全部维持**。唯一账面变化是**新增 D-C1**。
2. **D-C1 的定位建议（供裁定，非结论）**：它与 D-9 同根（Palink 把尾部块/注入计入深度锚定数组，ST 不计），但发生在 regex 通道而非 depth 插入通道；ASM-4 拆尾部块（D-1/D-5）会自动把膨胀从 +2 降到 +1（剩 WI depth 块），是否把 regex depth 改锚纯历史段（对齐 script.js:4445）建议与 D-9「禁单独修」同批裁定。
3. **D-4 的两卡合看点**：露缇雅（personality 非空 → 校准段出现）与猫娘（personality 空 → 不出现）构成该机制的正反两例，主脑 P-DEC-5（校准摘要去留）拍板时两卡口径均已闭合。
4. **验收自查（任务书两条）**：① dump W1 历史段 3 条 = SQL 分支消息数 3 ✓；② 差异映射覆盖首版 D-1~D-12 全部编号 + 新增 D-C1，无遗漏 ✓。
