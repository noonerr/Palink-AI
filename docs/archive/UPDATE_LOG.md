## 🆕 新增功能

### 1. 世界书系统 (World Book)
- 世界书管理界面
- 支持关键词匹配模式
- 世界书内容注入到 AI 对话上下文中

### 2. 剧情线系统 (Plotline)
- 剧情线管理
- 分支对话树支持
- 剧情节点导航

### 3. Token 统计面板
- 输入/输出 Token 统计
- 请求次数统计
- 按对话类型分类展示

### 4. 移动端优化
- 底部导航栏适配
- 响应式布局完善
- iOS Safari 安全区域适配

---

## 🔧 功能优化

### 1. iOS Safari 适配
- 添加顶部安全区域（灵动岛适配）
- 修复弹性滚动导致的空白问题
- 添加 `overscroll-behavior: none` 禁止橡皮筋效果

### 2. PWA 本地缓存
- Service Worker 缓存优化
- 静态资源离线缓存能力
- 版本更新提示机制
- 预计减少 80-90% 服务器带宽消耗

### 3. UI 调整
- 移除角色聊天开始页的世界书选择器（保留管理入口）
- Token 统计面板响应式布局优化（md 断点）
- 底部导航栏 z-index 层级提升

---

## 🐛 问题修复

1. 修复 iOS Safari 从下往上滑被空白覆盖的问题
2. 修复移动端底部导航栏被遮挡的问题
3. 移除冗余的 Service Worker 清理代码
