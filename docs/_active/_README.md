# docs/_active —— 新写文档请放这里

> 建立日期：**2026-10-05** ｜ 维护者：文档治理 agent
> **2026-10-05 之后新建的文档，一律放这里，不要放 `docs/` 顶层。**

## 为什么有这条规矩

`docs/` 顶层在 2026-10-05 之前堆了 **166 份** markdown，其中 34 份是做完即过期的一次性记录。
根因不是没人整理，是**没有归档规矩**——每份文档写完就留在原地，后来的人分不清
"这份还在用"还是"这份早就作废了"，只能在 166 份里靠文件名猜。

所以规矩是先定死，再动手搬。本目录是规矩的落地点。

## 一、放哪里（按文档性质选一个）

| 你写的是 | 放哪 | 例子 |
|---|---|---|
| 施工规格书 —— 动手前读的那份 | `_active/spec/` | `SPEC_MVU插件能力补齐_P0-P2_2026-10-05.md` |
| 排查/审计结论 —— **最可信的一类** | `_active/report/` | `REPORT_变量形状漂移_2026-10-05.md` |
| 交给下一个 agent 的提示词 | `_active/prompt/` | `PROMPT_MVU兼容补齐_交给Agent_2026-10-05.md` |
| 交接书、提测单、交付报告 | `_active/`（本层） | `HANDOFF_相册与渲染问题_2026-10-03.md` |

**判断依据是"读它的人要干嘛"**：要照着做的 → spec；要信它的结论的 → report；
要派活的 → prompt。

⚠️ 找文件时**顶层和 `_active/` 都要搜**，本次迁移只搬已过期的，活文件仍在顶层。
2026-10-05 之后的文件才适用本目录。

## 二、命名规矩

**保留现有多段前缀**（`SPEC_` / `REPORT_` / `PROMPT_` / `HANDOFF_` 等）。
全仓 166 份文档都靠这个前缀分类，索引脚本也按它统计——**不要改这套前缀**。

日期一律写在文件名里，格式 `_YYYY-MM-DD`。

```
✅ SPEC_MVU插件能力补齐_P0-P2_2026-10-05.md
❌ SPEC_MVU插件能力补齐.md              （无日期，无法判断新鲜度）
❌ MVU插件能力补齐_SPEC_2026-10-05.md    （前缀不在开头，索引漏抓）
```

⚠️ **文件名里的日期未必是真实日期**。归档时实测过 `CODE_QUALITY_AUDIT_REPORT.md`
文件名无日期、内容是 2026-05；`ST_COMPAT_FORK_AUDIT_2026-08-17.md` 内容首次提及却是 09 月。
**判新鲜度要读内容，不要信文件名。**

## 三、写完要做三件事（少一件就等于没归档）

1. **在文档首部自述状态** —— 这是别人唯一能免费判断新旧的地方。
   ```markdown
   # SPEC：xxx
   > 状态：待施工 / 施工中 / 已完工待验收 / 已作废（被 xxx 取代）
   > 授权：用户 2026-10-05 批准
   ```
   作废的**不要删**，在首部写明被谁取代——本目录纪律是只进不出。
2. **在 [`docs/OPEN_ISSUES.md`](../OPEN_ISSUES.md) 登记一条** —— 那里才是"现在该干什么"的唯一入口。
   本目录管文件放哪，那里管优先级，两件事分开。
3. **刷新文档总目录** —— 2026-10-05 起这一步是脚本，不用手数：
   ```bash
   python scripts/docs/gen_docs_catalog.py
   ```
   写完文档不跑这步，别人按名查找就找不到你这份。
   ⚠️ 实测：222 份文档里 **187 份首部没写状态标记**，
   所以"新目录清单"是别人找到你文档的唯一机器入口，不能靠人维护。

## 四、完工后怎么办

完工 ≠ 该一直躺在 `_active/`。等一批做完了，按 `docs/_archive/_README.md` 的判据收进
`_archive/YYYY-MM/`（按**内容真实日期**归月，不是文件名日期）。归档时同步改引用方路径，
搬完全仓 grep 复查断链。

## 五、纪律（沿用 AGENTS.md 备份规范的思路）

- **只进不出**：不删、不改写已有内容。纠错在标题下**加订正说明**，保留原始记录供追溯。
- **零入链才可搬**：搬之前全仓 grep 文件名，没有任何引用才动；有引用的先改引用再搬，
  否则断链是静默的。
- **不碰别人的在制品**：多 agent 共住，搬文件前确认目标文件不是别人正在写的。
