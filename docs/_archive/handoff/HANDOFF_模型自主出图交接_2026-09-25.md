## 施工时已按独立复核更正了 PLAN 的三处（勿"改回"）

1. **分派顺序**：内置工具分支在 dispatcher 里位于 `tool_executor` **之前**（PLAN 原文写"之后"是错的——角色 WS 主路径带前端 executor，内置调用会被转发给前端而失效）。匹配用**精确名** `is_builtin_tool()`（非前缀通配），防误吞前端插件工具。
2. **落库时序**：工具调用发生在流式生成中途、assistant 消息未落库 → handler 只做门控+暂存（`ModelImageRequestGate`），真实出图延后到消息落库后由既有出图钩子（`maybe_broadcast_image_event` / SSE 同名钩子）执行，事件契约与前端收敛 100% 复用 P1。`generate_image_for_message(prompt=...)` 直接采用模型给的画面描述（不过启发式模板）。
3. **合并触点**：tools 合并只有两个点但覆盖全部角色路径——`run_character_chat_generation`（一个函数覆盖 WS 主路径 + 群聊多发言者 + 续写三个调用点）与 `character_ext.py` SSE。PLAN 原文只写 character_ext.py 是不全的。
