## 这是什么

`docs/` 顶层堆了 166 份 markdown，其中绝大部分是"某次做一件事"的一次性记录：
实施计划、批次报告、审计发现、交接文档。它们在做完那天有价值，第二天就只是噪音。

本目录收容**已完成且已过保鲜期**的一次性文档，按**文档内容里的真实日期**分月存放。

## 归档判据（三条全中才收）

1. **零入链** —— 全仓 grep 文件名，没有任何文档引用它。搬走不会断任何链接。
2. **有真实日期且已过保鲜期** —— 早于 2026-09-30。
3. **不是长期参考** —— 长期有效的配置指南/契约类文档归 `docs/_reference/`，不归这里。
