### 3.2 [未做] `stop_by_id`

锚点（一手，已核实）：`st-plugins/third-party/JS-Slash-Runner-main/@types/function/generate.d.ts:216`
`declare function stopGenerationById(generation_id: string): boolean;`
语义见 `:225-265`：`generate`/`generateRaw` 可传 `generation_id`，据此停**指定**请求；
配合 `stopAllGeneration()`（`:222`，我们已有等价物 `window.stopAllGeneration`。

**为什么不做**：它要求生成侧有 id 句柄 —— `generate` 得收 `generation_id`、生成请求要按 id 登记、
停止要能只中止那一个流。Palink 侧这三件都没有（`part-07.ts:670 stopAllGeneration` 是
`requestParent('stopGeneration')` 全局停止），要做就等于在父侧新建一张"生成请求登记表"并改造
父侧生成/流式中止路径，属跨栈改动，超出本包“三项小收尾 + 批次三核查”的边界。
⛔ 不做“把按 id 折成全停”的近似实现（`palink-diag.ts:212` 的 token 就是这么写的）。
