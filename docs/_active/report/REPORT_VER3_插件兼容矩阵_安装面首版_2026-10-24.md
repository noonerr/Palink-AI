## ③ 护栏负向读数汇总

1. **单文本资源 1MB 上限**（`_zip_read_text` max_bytes=1_000_000，`backend/app/api/plugins.py:270`）——本批 4 例触发：
   - 干净 413 三例：JsRunner（3rd/js/jsoneditor.min.js）、Lorebook-Studio（dist/index.js）、CSTT（lib/full.js，证明非 manifest 声明资源同样被拦）。
   - 被掩盖一例：BlazeTracker——413 已抛出，但回滚期 DB 连接已断，psycopg2.OperationalError 作为二次异常把状态码打回 **HTTP 500**。**同因不同表现 ⇒ 前端若只看状态码会把护栏误报成服务器内部错误**，建议主脑关注（修复方向属另立议题，本报告只记录读数）。
2. **零半导入残留**：413 发生在资源读取阶段，先于 `_import_sillytavern_extension_manifest` 落库（plugins.py:416→658），5 个 failed 全部插件行未创建，无孤儿行。
3. **DB 连接池被长下载打穿**（Floating-MVU 两连败 + BlazeTracker 同栈）：import-url 在 `asyncio.to_thread` 下载窗口（91-101s）内连接池连接被对端回收，manifest 落库 commit（plugins.py:686）报 server closed the connection unexpectedly；短下载（5-17s）全数成功。**建议**（未实施，另立议题）：下载前 ping/重取连接。
4. **import-url 路线对大仓库不可用**：DeepLore（zip 35.3MB/467 条目）两次 import-url 均不可达——nginx `location /api/` 先 504（proxy_read_timeout 600s），服务端 to_thread 下载约 23min 后流中断、无行产生；宿主/容器实测 codeload 稳定 ~28KB/s、不支持 HTTP Range，git clone 亦 stall。**改走 POST /api/plugins/import multipart 上传同一 `_import_sillytavern_extension_zip` 管线（plugins.py:329）成功**——该兜底路线已实测可用。
5. **本批无读数的负向面**（如实记录，非通过）：内网/SSRF URL 拒绝、非 ZIP 压缩包 400、ZIP 条目 >2000（plugins.py:41/:337）、上传文件 >50MB（plugins.py:40）、单资产 base64 >5MB（plugins.py:277-279）——派发批次未包含此类样本，护栏行为无本批读数。
