## 4. 经验与坑（这两个月新增的，AGENTS.md 老坑不重复）

### 4.1 模型与子代理调度
- **Agent 工具并发实测=2**（超发即 `user concurrency limit exceeded` 秒死）；**动态工作流通道宽得多**（4 并发 Flash 稳定跑完 55 分钟普查）。要并发→走 CreateWorkflow。
- **断电/断机杀后台子代理不留尸**（任务注册表直接查无此人），但**半成品在盘**：靠「跑它的定向测试 + 审 diff 范围」收口（本案两次成功抢修）。
- 工作流 `world.run("bash", ...)` 在断电后走 WSL 中继会挂（`execvpe(/bin/bash) failed`）——**门禁改 py/npx 直调或让子代理自己跑测试、主脑本地复核**。
- Flash 能吃下精确派单（普查/矩阵/装配重排都干成了）；诀窍是**派单件引用文档而非内联长上下文**、判据写死、拿不准让标"待主脑裁定"。外部 agent（Qoder）质量同样高，执行件模式（PROMPT_ 对话包）成立。

### 4.2 Mimosa 与流程
- 组合命令易被误拦（cp dist + git add 源码同条、grep 模式含 `]*\.js`）——**拆开单跑**；写源码/测试文件必须 Write/Edit（heredoc/cat 必拦）；secret-scan 拦 `sk-` 形状测试夹具（改 `fixture-` 前缀，别绕扫描器）；容器内写文件必拦（探针走 Write 本地 + stdin 管道）。
- 静默失败守卫是真好用也会咬自己人：新增 except 必须接 `silent_failure.record/swallow`（本工程三次踩中：worldbook.py×9、part-02×1、ASM-4 设置读取×1）。
- 验收三板斧（主脑复验标准动作）：**独立重跑对方的定向测试；grep 锚点逐行核；只读 SQL 对账**。反证（改坏→红→还原绿）是硬通货。
- **零额度验收链**：dump 对照（结构）→ 新鲜眼审读（内容）→ 真机采样（行为，最后一步）。前两层这次全绿，第三层等钱。
