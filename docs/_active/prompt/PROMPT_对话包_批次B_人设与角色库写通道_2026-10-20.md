## 5. 硬性工程约束（违反任一条就退回）

- ⛔ **不许动 `frontend/dist`**（上线归主脑）；⛔ **不许重启/关停 Docker Desktop 或 compose 服务**——
  上一批有一次站点整段拒连的运维事件，成因虽未查实，但"动容器"已被移出施工方权限。
  后端如需自重建镜像：**先问主脑**，并在报告里写清镜像时间戳。
- `runtime-body/part-*.ts` 是注入 iframe 的**模板字符串**：里面**不许出现反引号，也不许出现 `${`，连注释里都不行**
  （注释也是字符串内容；上一批就因此把大字符串提前掐断，`tsc` 报 5 处 TS1005）；反斜杠**必须成对写**
  （单反斜杠会被模板求值吃掉，造成静默语义降级）。`tsc` 不检查字符串内部 ⇒ 必须让
  `generated-script-parse-guard` 测试过。
- 执行型测试只能用 **`COMPAT_V2_RUNTIME_ARTIFACT`**（求值后产物，与浏览器里那份逐字节同源）；
  拿源码文本 `new Function` 测 ⇒ 两个方向都会骗人。
- ⛔ **`typeof TavernHelper.xxx === 'function'` 不是实现证据**：`window.TavernHelper` 是 Proxy，
  未注册的名字也会返回"缺能力函数"。判存在只有两条：① 它出现在 `Object.keys(TavernHelper)`（自有属性）；
  ② 调用它之后，记录器里**不产生** `tavernhelper_key_unimplemented` / `missing_api` 记录。
- 测试文件的注释里不许出现 `*/`（会提前闭合块注释 ⇒ **整份测试变 `no tests`**，看起来有文件其实零断言）。
- 守卫测试不许为了变绿而改。唯一例外是**能力当天真的落地了**，此时必须三层同批交付：
  正向锚点断言 + 台账行订正 + 包H 报告计数订正（`13 + C + D = 134` 必须闭合）。
  ⛔ 不要从 `palink-diag.ts` 的 `ST_GAP_BY_NAME` 里**删**键名（会让双向守门测试红），只在注释标"已实现于 <提交>"。
