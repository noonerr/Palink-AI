```

        "regexCssFirstLine":"/* Styles for the debugger UI */", ...}
```
`regexCssHasImport=false` 且首行已是 debugger 样式本体 ⇒ **`@import` 被真正内联**，不是又换了个 URL。
`CNT_OTHER=0` ⇒ `macros.register is not a function` 与 `getScriptsByType(...).forEach` **都消失**。

⚠️ **覆盖边界（别当成"所有 @import 都修好了"）**：同一份探针的 A/B 小实验里，
**手工塞进 synthetic srcdoc 的** `@import "debugger.css"` 在同源帧下仍会产生 1 条 MIME 错
（`AB_mime_after_sameorigin_frame=1`）——那条不经过我们的注入管线。
本批修的只是**捆绑插件 CSS（当前=regex 的 debugger.css）**这条路；
将来若有第三方 CSS 引用一个不可解析的 `@import`，仍会报同样的错。
