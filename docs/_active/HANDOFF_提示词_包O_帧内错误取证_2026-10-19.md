## 3. 要做的事（只加字段，不改策略）

1. **帧内两个格式化函数**：兜底时不许只给 `unknown error`，按此顺序尽量填：
   `event.message` → `event.error.message` → `event.error.name` →
   `event.target.tagName + ' ' + (event.target.src || event.target.href)` → 最后才是 unknown。
2. **两个 handler** 改成上报**结构化**字段（`reportDiagnostic` 的 `detail` 里放 JSON，或新增
   `type:'frame-error'` 消息带独立字段）：
   ```
   { code, message, filename, lineno, colno, resourceUrl, tag, stackFirstLine }
   ```
3. **父侧** `CharacterCardRenderer.tsx:890-902` 的 `__palinkFrameErrors` 条目加上
   `colno` / `resourceUrl` / `tag`（上限 50 条不变）。
4. `part-a.ts` 的 onerror 补 `colno` 与失败资源 URL。
