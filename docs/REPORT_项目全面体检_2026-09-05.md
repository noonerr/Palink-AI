## 3. 🟡 技术债（影响有限，但该排期）

### T1 async 端点内同步 DB 调用——曾致全站死锁的架构风险原样健在

- 抽样比例（async def 内直接 `db.query/execute`）：**character_ext.py 33/38（87%）**、st_groups.py 10/13、worldbook.py 8/12、silly_tavern.py 22/78、chat.py 3/6。
- 2026-08-29 的 P0「并发首载 user_settings 竞态→事件循环死锁」的**根因结构没有变**，现在只靠 DB 侧 `idle_in_transaction_session_timeout=60s` 兜底（该参数设在 Postgres 侧，backend 代码零设置）。根治 = 高频写路径改 `asyncio.to_thread` 或 async session，需另立批次，动面前先拆文件（见 T2）。
