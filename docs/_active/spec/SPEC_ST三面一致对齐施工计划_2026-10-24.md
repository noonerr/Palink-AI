## 0. 怎么读这份文件

- **难度**：`S`＝单文件几十行；`M`＝跨 2–3 文件或前后端各一处；`L`＝动装配链/数据语义/架构；`XL`＝引入新子系统。
- **排序原则**（继承原排期）：① 先让"一致"**可测**，再修具体不一致；② 不可逆的（写库、放宽权限、动装配链）排后且要用户点头；③ 同难度挑真实插件/卡踩得最多的。
- **每批交付必给**：门禁数字（`bash scripts/gate.sh` 对应阶段 rc=0）、真机或容器内判据读数、反证（改坏会红）、只读 SQL 原文（涉及 DB 时）。
- **纪律**：提交带 pathspec、禁 `add -A`；改后端必须 `docker compose build backend && up -d`；改前端必须重建 dist 且入口指纹三步核验；并行会话同文件串行；⛔ 装配链批次动工前先做基线 dump 备份。
